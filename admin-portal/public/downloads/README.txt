To build the Android APK:

1. Install Android Studio or Gradle
2. Navigate to /root/digitalchain/rider-android
3. Run: ./gradlew assembleDebug
4. APK will be generated at: app/build/outputs/apk/debug/app-debug.apk
5. Copy APK here: cp app/build/outputs/apk/debug/app-debug.apk /opt/digitalchain/admin-portal/public/downloads/rider-app.apk

Then it will be available at: https://jugesh.digitalchain.in/downloads/rider-app.apk
